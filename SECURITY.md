# Security policy

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

Please report security problems **privately**, not in a public issue. Use GitHub's private vulnerability reporting:
open the repository's **Security** tab and choose **Report a vulnerability**
(<https://github.com/pkonowrocki/casio-pager/security/advisories/new>).

Include what you found, how to reproduce it, and the app version. You should get a reply within a week. Fixes are
released as a new version and credited in the advisory unless you prefer otherwise.

## What matters here

The app reads notifications and talks to a watch over Bluetooth. Reports about leaking message text or names, the
diagnostics link or server, the signing of releases, or an exported component being abusable are all in scope.
